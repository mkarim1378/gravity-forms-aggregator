# Gravity Forms Aggregator

افزونه وردپرس برای تجمیع و اکسپورت ورودی‌های چند فرم Gravity Forms در یک فایل CSV یا Excel.

## خلاصه

این ابزار به مدیر سایت اجازه می‌دهد:

- فرم‌های Gravity Forms را لیست کند
- چند فرم را با چک‌باکس انتخاب کند
- بازه زمانی تعیین کند
- ورودی‌های انتخاب‌شده را از دیتابیس بخواند
- خروجی تجمیعی CSV و Excel دانلود کند

## نسخه‌های بعدی (خارج از MVP)

- هشدار فرم‌های قدیمی که هنوز ورودی می‌گیرند

- اعلان‌ها (ایمیل / تلگرام)
- ذخیره preset انتخاب‌های پرتکرار
- گزارش‌های ماهانه
