# Export Spec — مشخصات خروجی

## فرمت‌های پشتیبانی‌شده

### CSV

مناسب برای:

- Excel
- Google Sheets
- پردازش‌های سریع

**الزامات:**

- encoding صحیح (UTF-8 with BOM برای سازگاری Excel فارسی)
- header استاندارد در ردیف اول
- escape صحیح مقادیر دارای کاما و خط جدید

### Excel (XLSX)

مناسب برای:

- استفاده مدیریتی
- فیلترهای بعدی
- فرمول‌نویسی و گزارش‌گیری

**الزامات:**

- باز شدن بدون مشکل در Excel و Google Sheets
- همان data model CSV
- کتابخانه memory-friendly

## ستون‌های خروجی

### حداقل (MVP)

| ستون | توضیح |
|------|-------|
| Form ID | شناسه فرم |
| Form Title | عنوان فرم |
| Entry ID | شناسه ورودی |
| Entry Date | تاریخ ثبت ورودی |
| Field Label | برچسب فیلد |
| Field Value | مقدار فیلد |

### اختیاری (نسخه بعدی)

| ستون | توضیح |
|------|-------|
| Source Page URL | آدرس صفحه ارسال |
| Status | وضعیت entry |
| Notes | یادداشت‌ها |

## حالت‌های Export

| حالت | توضیح | MVP |
|------|-------|-----|
| All fields | همه فیلدهای ورودی | ✅ پیش‌فرض |
| Phone fields only | فقط موبایل، تلفن و … | ❌ فاز بعد |

## فیلتر تاریخ

### ورودی‌ها

- **From Date** — از تاریخ
- **To Date** — تا تاریخ

### رفتار مورد انتظار

| وضعیت | رفتار |
|-------|-------|
| هر دو تاریخ خالی | همه داده‌ها |
| فقط From | از آن تاریخ به بعد |
| فقط To | تا آن تاریخ |
| هر دو پر | فقط ورودی‌های داخل بازه (شامل مرزها — در پیاده‌سازی تعیین شود) |

### الزامات

- فقط ورودی‌هایی که تاریخ ثبت آن‌ها داخل بازه است استخراج شوند
- رفتار مشخص و قابل فهم برای هر ترکیب ورودی
- validation تاریخ نامعتبر (From > To)

## نام فایل (پیشنهادی)

```
gf-export_{YYYY-MM-DD}_{record-count}.{csv|xlsx}
```
