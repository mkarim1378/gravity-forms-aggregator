# UX — تجربه کاربری

## جریان کلی

```
ورود به صفحه ابزار
    ↓
انتخاب فرم‌ها (checkbox)
    ↓
تعیین بازه تاریخ
    ↓
پیش‌نمایش (شمارش + هشدار)
    ↓
دانلود CSV یا Excel
```

## صفحه 1: انتخاب فرم‌ها

| عنصر | رفتار |
|------|-------|
| لیست فرم‌ها | نمایش همه فرم‌های Gravity Forms |
| Checkbox | کنار هر فرم — انتخاب چندگانه |
| جست‌وجو | فیلتر با نام یا ID (nice-to-have) |
| انتخاب همه | تیک زدن همه فرم‌ها |
| لغو انتخاب همه | برداشتن همه تیک‌ها |

## صفحه 2: فیلتر تاریخ

| فیلد | توضیح |
|------|-------|
| From Date | تاریخ شروع بازه |
| To Date | تاریخ پایان بازه |

رفتار تاریخ در [EXPORT-SPEC.md](EXPORT-SPEC.md) تعریف شده.

## صفحه 3: پیش‌نمایش

قبل از خروجی، نمایش:

- تعداد فرم‌های انتخاب‌شده
- تعداد کل رکوردهای پیدا شده
- بازه تاریخ انتخاب‌شده
- هشدار برای فرم‌هایی که در بازه داده ندارند

## صفحه 4: خروجی

| دکمه | عمل |
|------|-----|
| Download CSV | دانلود فایل `.csv` |
| Download Excel | دانلود فایل `.xlsx` |

## گام‌های اجرایی (منطق عملکرد)

1. کاربر وارد صفحه ابزار می‌شود
2. فرم‌ها را می‌بیند
3. فرم‌های موردنظر را تیک می‌زند
4. بازه تاریخ را مشخص می‌کند
5. ابزار کوئری را به دیتابیس می‌زند
6. داده‌های ورودی فرم‌ها را جمع می‌کند
7. خروجی یکپارچه می‌سازد
8. فایل CSV یا Excel دانلود می‌شود

## ملاحظات UX

- پیام خطای واضح برای تاریخ نامعتبر
- غیرفعال کردن دکمه export وقتی هیچ فرمی انتخاب نشده
- نمایش loading هنگام شمارش یا تولید فایل
- نام فایل دانلودی شامل تاریخ و تعداد رکورد (پیشنهادی)
