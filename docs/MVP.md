# MVP — Minimum Viable Product

## تعریف

نسخه اولیه فقط نیازهای ضروری را پوشش می‌دهد تا مدیر بتواند سریع چند فرم را انتخاب کند، بازه تاریخ تعیین کند و خروجی CSV/Excel بگیرد.

## قابلیت‌های MVP (ضروری)

- [ ] نمایش لیست فرم‌های Gravity Forms
- [ ] امکان انتخاب چند فرم با چک‌باکس
- [ ] امکان تعیین از تاریخ / تا تاریخ
- [ ] استخراج ورودی‌های فرم‌های انتخاب‌شده
- [ ] خروجی CSV
- [ ] خروجی Excel
- [ ] نمایش تعداد رکوردهای قابل خروجی قبل از دانلود
- [ ] بدون ذخیره‌سازی اضافی در دیتابیس جدید

## خوب است ولی غیرضروری

- جست‌وجوی فرم با نام یا ID
- انتخاب همه / لغو انتخاب همه
- شمارش رکورد قبل از دانلود (در لیست ضروری هم آمده — اولویت بالا)
- هشدار فرم بدون رکورد

## تصمیم خروجی: حالت A (پیشنهاد MVP)

**حالت A — خروجی کامل فرم‌ها:** همه فیلدهای ورودی در خروجی.

**حالت B — فقط فیلدهای مشخص:** مثلاً موبایل، تلفن، نام، ایمیل.

> **تصمیم:** برای MVP حالت A انتخاب شده — ساده‌تر و عمومی‌تر.

در نسخه بعدی می‌توان گزینه‌ای اضافه کرد:

```
Export mode: All fields / Only phone fields
```

## MVP فشرده (تحویل سریع‌تر)

اگر زمان محدود باشد، MVP در ۴ فاز قابل تحویل است:

1. تحلیل ساختار و scope
2. UI انتخاب فرم + date range
3. استخراج داده + CSV
4. Excel + validation + polish

جزئیات فازها در [ROADMAP.md](ROADMAP.md).
